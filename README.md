# Potato Paint
Potato Paint is a lightweight, optimized, cross-platform painting application. I made it because I have a tablet (the aforementioned "potato") incapable of running any painting apps fast enough to be useful.

<img width="256" height="256" alt="icon" src="https://github.com/user-attachments/assets/6cb0d09c-da45-4e6b-bbb2-daadab24998d" />

Grab the builds from here: https://michaeljared.itch.io/potato-paint

## Features
- Cross platform: Windows, Linux, Android, and Web
- Layers: adding, deleting, re-ordering
- 20 do/undo steps
- Full transparency
- 100% hideable UI so maximize screen space
- Controllable brush size, hardness and spacing (for eraser as well)
- Brush settings saved with each layer
- Eye dropper
- Optimized C++ paint brush code (made with GDextension)
- Saving/loading projects
- Bucket fill
- Pen pressure (in theory, never tested)
- Auto-saving
